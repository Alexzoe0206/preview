How to read

選合作夥伴時，
這些數字怎麼用。

能說明

亞述做過哪些產業、哪些能力常一起出現、案例分布在哪些年代。可以拿來找和你產業、問題相近的案例。

不能說明

成效、合約數或公司年資。附數字的 7 筆全是交付證據（日期、期次、文件），附成效測量的是 0 筆。

建議怎麼看

先用 案例篩選 找相近的案例，看它的交付證據與資料完整度標籤，再到合作的 診斷階段 一起確認要衡量什麼。

數字定義算法限制
90筆案例與提案案例庫中所有亞述案例與提案（已排除 1 筆非亞述紀錄）。以專案或可分辨的子專案為單位。+

算法len(cases)；排除筆數 = len(cases)-len(A)；案例與提案庫筆數 = len(A)。

限制不等於獨立合約數；保守合併疑似同案族後為 86 組。

72筆已交付紀錄狀態為已交付的紀錄，包含內部總表與公司簡報列示的歷史案，以及明示部分交付的案件。+

算法len(D)；包含內部總表或公司簡報自述案例，及已明示部分交付的案；不等於全數結案或已上線。

限制不等於全數結案或已上線；每個案例頁都附上交付範圍。

18筆提案與研究報價階段或提案未得標者，另區呈現。+

算法案例與提案筆數 − 已交付筆數

限制只有提案而無得標結果者，不假定未得標，也不列為成功案例。

8個主產業每案依服務對象與專案情境歸入一個主產業。+

算法len(set(c.industry for c in A))；每案一個主產業，依服務對象與專案情境編輯分類。

限制「其他」含企業服務等未歸類者。

17年案例活動跨度（2010–2026）已交付案例中有年份證據的最早與最晚年份，含首尾日曆年。+

算法只取 D 的 year.observed_years 非空值；min/max 為已知活動邊界；跨度=max-min+1（含首尾的日曆年份），不是持續合作年數或公司成立年資。

限制不是連續合作年數，也不是公司年資。公司成立年份 2006 另依公司簡報記載。

17年有案例證據的年度數已交付案例的已知活動年份集合大小。+

算法len(set(y for c in D for y in c.year.observed_years))；不填補只記起訖或跨年延續案的中間年份。

限制只記起訖的跨年案不補中間年份。

6類服務能力使用者研究、UI/UX、系統與平台、HMI 與機器人介面、品牌與官網、數位顧問與 AI 流程。+

算法每個服務 s：sum(s in c.services for c in A)；多選，不將各服務合計當案例總數。

限制可複選，各服務筆數加總不等於案例數。

7筆跨境客戶／合作／市場（下限）來源明示海外客戶、合作或市場的已交付紀錄。+

算法sum(bool(c.cross_border_evidence) for c in D)；只表示來源明示海外客戶、合作或市場；不將外商品牌、英文文件、參展地點當作跨國專案證據。此為資料下限。

限制外商品牌、英文文件或參展地點不算；此為資料下限。

5年單一品牌最長記載合作期間公司簡報記載的智慧電視整體合作期間（2012–2016）。+

算法依客戶聚合 collaboration_periods 中來源明載連續合作區間，計算聯集年份數；其他客戶回傳 null，不由完成年份之差假定連續合作。

限制企業合作期間，非單案工期；其他客戶未記載連續期間者不推算。

7筆附交付證據數字的紀錄有可定位來源的交付證據數字：文件清點人數、交付期次、驗收或上線日期。+

算法sum(bool(c.results) for c in A)；results 可含日期、規模與列示名單，不代表效益因果證明。planned_metrics 與 disputed_metrics 完全排除。

限制全部屬「交付證據」，證明做了什麼、交到哪裡，不是成效；規劃值與有爭議的數字完全排除。

0筆附成效測量的紀錄有基準、期間或樣本的成效數字，例如處理時間、錯誤率、使用量或滿意度。+

算法results 中證據類型屬成效測量（measured_outcome／pre_post_measurement／usage_metric／satisfaction_survey）的紀錄數

限制目前為 0。本站不以交付數量、服務數或推估值代替成效。
